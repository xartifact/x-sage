# 语境 Context

## 核心内容（molecule）

语境是决定概念如何具体生效的环境条件。同一个概念在不同语境下含义和作用完全不同——语境不是"一堆其他概念的集合"，而是使其他概念获得具体意义的前提条件本身。

### 为什么是 L0

如果去掉语境，所有概念都变成无条件的普遍命题。"效率"在初创公司的语境下意味着快速迭代，在医疗系统的语境下意味着零差错——没有语境，"效率"是一个空洞的符号。语境不能被定义为其他概念的组合，因为它是使其他概念获得意义的元条件。

### 核心属性

1. **条件性**：语境不直接参与推理，但它决定推理的前提哪些成立、哪些不成立。它像物理实验的初始条件——不参与方程本身，但决定了方程的解。
2. **层级性**：语境可以嵌套。一个产品的语境（市场阶段）内部包含用户的使用场景语境，后者又包含即时的交互语境。层级越深，约束越具体。
3. **时变性**：语境不是静态的。项目的阶段变化、市场的演变、个人的成长——语境的变迁使原本有效的推理失效，原本矛盾的价值变得兼容。

### 跨域实例

| 域 | 语境实例 |
|----|---------|
| 产品 | 使用场景、市场阶段、技术环境、竞争格局 |
| 个人思想 | 人生阶段、关系情境、文化背景、历史时刻 |

### 深层含义

语境与"背景知识"不同。背景知识是可以被显式列举的信息集合；语境是使这些信息获得解释框架的条件结构。当你把语境还原为信息集合时，你丢失了"为什么这些信息在这个场景下重要"的元信息——而这正是语境的核心。

## 张力与开放问题

- **语境边界**：如何划定一个语境的边界？语境之间的过渡是离散的跳跃还是连续的渐变？当前系统没有形式化的语境边界机制。
- **语境压缩**：如何在 MANIFEST 中高效表示语境信息？如果每个概念都要标注生效语境，原子清单会迅速膨胀。
- **跨语境推理**：在语境A中成立的推理，能否迁移到语境B？这需要一种"语境相似度"度量，但目前未定义。
