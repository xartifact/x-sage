# 价值 Value

## 核心内容（molecule）

价值是对主体重要的事物——它是所有目标选择的依据、所有决策的终极理由。

### 为什么是 L0

"价值本身重要"这件事无法再往下追溯。所有"目标"都在追求某种价值，所有"决策"都在价值之间做取舍，但价值的终极性使得它不能被分解为更基础的概念。你可以列举具体的价值（效率、公平、自由），但"为什么这些是价值"这个问题，系统内没有更底层的概念来回答——它是公理层的终点。

### 核心属性

1. **不可推导性**：价值不是从逻辑推理中得出的结论，而是推理本身的前提。你可以说"因为效率重要，所以选择方案A"，但"效率重要"这个前提无法从系统内其他概念推导。
2. **多元性**：不存在单一价值能覆盖所有情境。不同主体、不同语境下，价值的优先级和内容不同。多元性是张力概念的根源。
3. **可冲突性**：两个价值可以同时为真，但在同一语境下无法同时最大化。效率与质量、自由与安全、速度与深度——冲突不是价值的缺陷，而是其固有属性。

### 跨域实例

| 域 | 价值实例 |
|----|---------|
| 产品 | 用户价值、商业价值、工程质量、用户体验 |
| 个人思想 | 价值观、道德直觉、判断标准、人生追求 |

### 深层含义

价值与偏好的区别：偏好是可以被更高层价值解释的选择倾向，而价值是解释链的终点。当你说"我偏好X"，可以追问"为什么"——直到答案不再是"因为Y更重要"，而是"X本身重要"，你就抵达了价值层。

## 张力与开放问题

- **价值的相对性**：价值是否因主体不同而完全相对？如果存在跨主体的普世价值，系统如何表达？当前 `confidence: confirmed` 是否过于绝对？
- **隐含价值**：很多决策背后有未被显式表述的价值——系统如何捕获这些隐含价值？
- **价值与信念的边界**：信念（Belief）是否是一种特殊的价值？如果信念升至 L0，两者的关系需要重新定义。
