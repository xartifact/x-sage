# 主体 Agent

## 核心内容（molecule）

主体是知识库中最基础的概念——它是行动、意图、价值判断的不可还原的载体。

### 为什么是 L0

试图定义"主体"时，你只能诉诸自然语言（"能行动的实体""有意图的存在"），无法引用系统内任何其他概念。反过来，系统内几乎所有概念都直接或间接以主体为前提：价值是对主体而言的重要；目标是主体想要达到的状态；约束是限制主体的行动空间；决策是主体在张力中的选择。去掉主体，整张概念图失去锚点。

### 核心属性

1. **意向性**：主体不是被动对象，它有方向——追求某些状态、回避某些状态。这种意向性是目标和需求的根源。
2. **情境嵌入**：主体始终处于特定语境之中，它的行动能力、价值判断都受语境塑造。但主体不等同于语境——它有超越当前情境的持续身份。
3. **边界性**：主体有边界——谁是主体、谁不是，这个区分本身影响一切后续推理。团队与个人、用户与系统、自我与他人的边界划定，直接决定价值归属和责任分配。

### 跨域实例

| 域 | 主体实例 |
|----|---------|
| 产品 | 用户、团队成员、利益相关者、组织 |
| 个人思想 | 自我、他人、群体、共同体 |

### 深层含义

主体不是"人"的同义词。一个组织可以是主体（有意图、能行动），一个 AI 系统在某些语境下也可以被当作主体来推理。关键判断标准是：**它能否被当作价值判断和行动选择的归属点？** 如果能，它就在这个推理场景中充当主体。

## 张力与开放问题

- **主体边界模糊**：组织中的个体既是独立主体又是组织的构成部分——主客体同构的张力未被系统处理。
- **AI 作为主体**：当 AI 系统表现出自主行动时，是否应被当作主体？这涉及"主体"概念的边界是否需要收缩。
- **多主体冲突**：多个主体的价值在同一语境下冲突时，系统当前没有优先级机制——这实际上指向 `tension` 概念。
