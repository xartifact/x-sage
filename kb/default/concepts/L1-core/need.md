# 需求 Need

## 核心内容（molecule）

需求是主体在特定语境下，因价值缺口导致的必须被满足的状态。如果说目标是"想要达到"的积极追求，需求就是"不得不满足"的底线约束——它标记的是缺失，而非向往。

### 从 L0 推导

- **主体**：需求必须归属于某个主体——没有主体的需求是悬空的。
- **价值**：需求源自价值缺口。当某个价值未被满足时，它转化为"必须被满足"的紧迫感。安全是价值，对安全的需求意味着当前安全状态低于底线。
- **语境**：同一价值在不同语境下的底线不同。在和平语境下，安全需求可能是"基本保障"；在危机语境下，安全需求可能是"绝对防护"。

### 核心属性

1. **紧迫性**：需求比目标更具紧迫感。目标未达成是遗憾，需求未满足是危机。这种紧迫性决定了优先级——在资源有限时，需求先于目标。
2. **底线性**：需求定义的是"不可低于"的阈值，而非"尽可能高"的优化目标。满足需求意味着消除缺口，而非追求最优。
3. **层级性**：需求可以分层。马斯洛需求层次是一个经典框架：生理需求→安全需求→社交需求→尊重需求→自我实现。低层需求未满足时，高层需求难以激活。

### 跨域实例

| 域 | 需求实例 |
|----|---------|
| 产品 | 用户需求、功能需求、非功能需求（性能/安全/可用性） |
| 项目 | 资源需求、信息需求、依赖需求 |
| 个人 | 心理需求（安全感/归属感/自主性）、物质需求 |

### 需求与目标的辩证关系

需求与目标不是简单的上下级关系。在实践中，满足需求的方式会塑造新目标，而追求目标的过程也会暴露新需求。两者的 `contradicts` 边（confidence: hypothetical）标记了一个值得注意的张力：有时满足需求会阻碍目标（为安全牺牲速度），有时追求目标会忽视需求（为增长透支健康）。

## 张力与开放问题

- **需求的伪识别**：用户表达的"需求"经常是解决方案而非真实需求。"我需要搜索功能"可能是"我需要快速找到信息"的解决方案。如何区分真实需求与伪需求？
- **需求的无意识性**：有些需求主体自身未意识到（隐性需求），但它们在行为中反复显现。系统如何捕获未表达的需求？
- **需求膨胀**：需求有自然膨胀的趋势——每满足一个需求，新需求随之产生。如何在知识库中标记需求边界？
