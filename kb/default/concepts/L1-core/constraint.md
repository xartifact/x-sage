# 约束 Constraint

## 核心内容（molecule）

约束是在特定语境下限制主体行动空间的条件。它定义了"不能做什么"或"必须怎么做"——是可能性的边界。

### 从 L0 推导

- **主体**：约束必须作用于某个主体的行动空间。没有主体的约束是物理定律——它不限制行动，因为根本不存在可选行动。约束之所以有意义，是因为主体本来可以做出其他选择。
- **语境**：约束是语境的具体化。语境决定了哪些条件生效，约束是这些条件对行动空间的直接限制。时间预算只在项目语境中是约束，在休闲语境中不是。

### 核心属性

1. **双面性**：约束既是限制也是赋能。限制选择空间的同时，它消除了无效选项，降低了决策的认知负担。好的约束让决策更容易，坏的约束让决策不可能。
2. **可变性**：约束不是永恒的。有些约束可以通过行动改变（预算可以通过融资增加），有些约束是硬性的（物理定律、时间不可逆）。区分硬约束和软约束是决策的前提。
3. **隐蔽性**：最重要的约束往往不是最显眼的。时间约束人人可见，但认知偏见、组织惯性、技术债务这些隐性约束才是真正的行动空间限制者。

### 跨域实例

| 域 | 约束实例 |
|----|---------|
| 产品 | 技术约束、资源约束、合规要求、平台限制 |
| 项目 | 时间、预算、人力、依赖关系 |
| 个人 | 能力边界、外部条件、承诺、健康 |

### 约束与目标的张力

约束与目标之间有天然的 `contradicts` 关系：目标想要扩展行动空间，约束限制行动空间。但这个矛盾是创造性的——所有有意义的创新都是在约束中找到的，而非在约束消失后找到的。无约束的自由不产生创造性决策，只产生随意选择。

## 张力与开放问题

- **约束的隐性化**：很多约束不被当作约束——它们被内化为"事情就是这样的"。如何识别被自然化的约束？
- **约束的可协商性**：在实际中，很多"硬约束"其实可以协商。如何标记约束的可协商程度？
- **约束的传导性**：一个层面的约束会传导到下游——技术约束传导为产品约束，产品约束传导为用户体验约束。系统尚未建模约束传导链。
