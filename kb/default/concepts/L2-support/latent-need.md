# 隐性需求 Latent Need

## 核心内容（molecule）

隐性需求是主体未意识到但行为中反复显现的需求。与伪需求不同（伪需求是解决方案伪装成需求），隐性需求是真实需求但主体自身未觉察——它以症状、反复行为和情绪反应的形式间接表达。

### 从 L1 推导

- **need**：隐性需求是需求的一种未识别形式——它满足需求的所有定义（价值缺口、必须被满足），只是主体没有将其识别为"需求"。没有被识别的需求仍然驱动行为，只是以非最优的方式。
- **agent**：隐性需求归属于主体——但主体需要外部视角才能识别它。自我觉察是识别隐性需求的前提，但多数主体缺乏充分的自我觉察。
- **value**：隐性需求植根于主体未充分理解的价值。当主体感受到价值缺口但无法命名这个价值时，需求就是隐性的。

### 核心属性

1. **症状性表达**：隐性需求不通过"我需要X"表达，而是通过行为模式表达。反复检查手机（隐性需求：安全感/连接感）、回避特定社交场景（隐性需求：自主性/尊重）、过度准备（隐性需求：确定性/控制感）。
2. **满足后显现**：隐性需求在被满足后才可能被识别——"原来我一直在找的是这个"。这种事后识别的特性使得隐性需求难以在需求收集阶段被发现。
3. **文化嵌入性**：很多隐性需求源于文化——集体文化中个体的自主性需求、个体文化中个体的归属感需求。这些需求因文化"盲点"而隐性化。

### 识别方法

| 方法 | 原理 | 适用场景 |
|------|------|---------|
| 行为模式观察 | 重复行为指向未被满足的需求 | 用户研究、组织行为分析 |
| 情绪映射 | 持续的负面情绪标记价值缺口 | 个人发展、用户满意度分析 |
| 对比分析 | 同一主体在不同语境下的行为差异揭示语境敏感的隐性需求 | 跨文化研究、A/B测试 |
| 已满足者回溯 | 已满足需求的人回溯"之前缺什么" | 产品迭代、用户访谈 |

## 张力与开放问题

- **与伪需求的对比**：伪需求是"说的不对"（解决方案伪装成需求），隐性需求是"没说出来"（需求存在但未被识别）。两者都需要超越用户表达去发现真实需求，但方法论不同——伪需求需要追问"为什么"，隐性需求需要观察"做什么"。
- **隐性需求的投射风险**：观察者可能将自身的隐性需求投射到被观察者身上——"我觉得他们需要X"可能反映的是观察者的需求而非被观察者的需求。
- **需求发现 vs 需求发明**：识别隐性需求是"发现"还是"发明"？如果主体之前从未有过这个需求，满足它是否创造了之前不存在的依赖？
