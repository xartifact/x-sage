# 目标漂移 Goal Drift

## 核心内容（molecule）

目标漂移是手段逐渐变成目的本身的过程。原本作为实现路径的工具、流程或指标，不知不觉间成为了主体追求的目标——而原始目标被遗忘或替代，主体往往未察觉这种转换。

### 从 L1 推导

- **goal**：目标漂移是目标自身的一种退化形式——目标是"想要达到的状态"，漂移后目标变成了"正在执行的动作"。它仍然是目标（驱动行为），但方向已经偏移。
- **context**：目标漂移在长期执行中最容易发生——语境的持续性使得"一直做的事"被自然化为"应该做的事"。短周期任务很少漂移，长周期项目几乎必然漂移。
- **tension**：漂移的根源常常是张力——当原始目标与当前约束产生张力时，完成约束内的"可做之事"比追求"应达之境"更容易，主体逐渐转向可做之事。

### 核心属性

1. **渐进性**：目标漂移不是瞬间切换，而是渐进偏移。每次微小的方向调整看似合理，但累积效果使最终方向与初始目标显著偏离。温水煮青蛙——漂移的渐进性使得它难以被实时察觉。
2. **自我合理化**：漂移后的目标总能找到合理化叙事。"我们一直在优化这个指标"可以被包装为"我们在追求卓越"——区别在于原始目标可能不是优化这个指标。
3. **可检测性**：目标漂移可以通过定期回溯检测——问"我们最初为什么要开始做这件事"，如果答案与当前行为方向不同，漂移已发生。

### 典型模式

| 模式 | 原始目标 | 漂移后目标 | 检测信号 |
|------|---------|-----------|---------|
| 指标崇拜 | 提升用户体验 | 提升 DAU 指标 | 指标上升但用户投诉增多 |
| 流程固化 | 保证交付质量 | 遵循流程步骤 | 流程完成但交付无人使用 |
| 工具迷恋 | 解决问题 | 精通工具 | 工具讨论远多于问题讨论 |
| 增长成瘾 | 服务用户 | 获取更多用户 | 用户数量增长但满意度下降 |

## 张力与开放问题

- 与 `goal` 的 contradicts 关系：漂移意味着"当前声称的目标"与"最初真实的目标"之间的不一致。这不是两个不同主体的目标冲突，而是同一主体在不同时间点的目标偏移。
- **漂移 vs 适应**：如何区分"目标漂移"（负面的方向丢失）和"目标适应"（正面的方向调整）？语境变化时，修改目标是适应而非漂移——关键区别在于：修改是有意识的决策，漂移是无意识的偏移。
- **系统性漂移**：组织比个人更容易漂移——个人可以自我反思，但组织的反馈回路更长、更弱。
