# 硬约束与软约束 Hard & Soft Constraint

## 核心内容（molecule）

硬约束是不可通过行动改变的约束条件，软约束是可在资源投入后调整的约束。区分二者是有效决策的前提——把软约束当硬约束对待导致不必要的妥协，把硬约束当软约束对待导致无谓的挣扎。

### 从 L1 推导

- **constraint**：硬约束和软约束是约束的两种性质——同一约束在不同语境下可能是硬的也可能是软的。"时间不够"在截止日期前是硬约束，在新项目规划时是软约束。
- **agent**：约束的硬度取决于主体的能力边界——对某个主体是硬约束的，对能力更强的主体可能是软约束。硬约束是"当前主体不可改变"，而非"绝对不可改变"。
- **context**：语境决定约束的硬度——同一条件在不同语境下硬度不同。预算在执行阶段是硬约束，在规划阶段是软约束；物理定律在工程中是硬约束，在理论探索中不是约束。

### 核心属性

1. **可协商性梯度**：约束的硬度不是二元的，而是一个梯度。从"物理上不可能"到"需要更多资源"到"需要重新谈判"，硬度逐渐降低。决策时需要判断约束在梯度上的位置。
2. **伪装性**：很多软约束被当作硬约束——因为声明"这是硬约束"可以避免谈判、减少决策负担。"预算不可增加"在90%的情况下是软约束（可以融资、可以重新分配），但被当作硬约束以简化决策。
3. **识别价值**：区分硬约束和软约束的价值不在于"突破约束"——而在于**不要在硬约束上浪费资源**。在硬约束内找到最优解，在软约束上投资以扩展空间。

### 识别方法

| 问题 | 判断依据 |
|------|---------|
| "如果有更多资源，这个约束能改变吗？" | 能 → 软约束；不能 → 硬约束 |
| "这个约束在所有语境下都成立吗？" | 否 → 软约束；是 → 可能是硬约束 |
| "过去有人成功改变过这个约束吗？" | 有 → 软约束；没有 → 可能是硬约束 |
| "声明这个约束是硬约束的人有动机吗？" | 有 → 可能是伪装的软约束 |

## 张力与开放问题

- **约束硬度的主观性**：同一个约束，不同主体对其硬度的判断可能不同。能力强的主体倾向于看到更多软约束，能力弱的倾向于接受更多硬约束——这是合理的还是认知偏差？
- **约束谈判的成本**：验证一个约束是软约束本身需要投入——谈判、探索、试错。当验证成本高于约束内的妥协成本时，接受硬约束假设更理性。
- **硬约束的创新价值**：硬约束不是只有负面——它迫使创新。当资源无限时，解决方案趋向平庸；当约束严苛时，解决方案趋向创造性。
