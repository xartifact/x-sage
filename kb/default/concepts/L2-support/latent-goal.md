# 隐含目标 Latent Goal

## 核心内容（molecule）

隐含目标是未被显式表述但实际驱动主体行为的目标。它与声明的目标之间存在系统性偏差——人们说的和他们做的往往指向不同的方向。

### 从 L1 推导

- **goal**：隐含目标是目标的一种存在形式——它具备目标的所有属性（指向未来状态、归属于主体、基于价值），只是未被显式表达。
- **agent**：隐含目标必须归属于某个主体——但这个主体可能不愿承认该目标的存在。组织中的"潜规则"往往指向隐含目标。
- **context**：隐含目标的可识别性随语境变化。在安全语境下，主体可能承认隐含目标；在政治语境下，承认隐含目标意味着暴露真实意图。

### 核心属性

1. **行为推断性**：隐含目标只能从行为模式中推断，而非从声明中获取。当声明目标和实际行为持续偏离时，隐含目标就在行为的方向上。
2. **防御性**：主体往往有动机隐藏隐含目标——因为它可能与社会规范、组织价值观或个人理想自我冲突。这种防御性使得识别隐含目标需要间接手段。
3. **预测优越性**：在预测主体未来行为时，隐含目标比声明目标更有预测力。"听其言不如观其行"——行为揭示真实目标。

### 识别方法

| 信号 | 含义 |
|------|------|
| 声明目标与行为持续偏离 | 行为方向即隐含目标 |
| 资源分配与声明优先级不匹配 | 资源流向即真实优先级 |
| 对某些选项的强烈回避 | 回避的方向指向隐含目标的对立面 |
| 话语中的系统性遗漏 | 被系统性回避的话题区域 |

## 张力与开放问题

- 与声明的 `goal` 的 contradicts 关系：隐含目标的存在意味着声明目标可能只是"表演"，而非真实的行动方向。这对决策分析有重大影响。
- **识别可靠性**：从行为推断意图存在归因错误的风险——行为偏离可能是因为能力不足而非隐含目标不同。
- **伦理性**：在组织中识别并公开隐含目标可能导致信任危机——识别和使用隐含目标之间的界限模糊。
