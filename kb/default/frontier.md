# 激活边界 frontier.md

> 记录已识别但未深入的节点和未解张力。每次会话结束后更新。

## 未决概念

| 概念 | 来源 | 未解问题 | 优先级 |
|------|------|----------|--------|
| Belief (信念) | l0-candidates.md 待确认项 | 是否应升为 L0 公理？取决于个人思想体系是关于认知框架还是行动系统 | 高 |

## 概念内张力

| 张力 | 涉及概念 | 状态 | 说明 |
|------|---------|------|------|
| 主体边界模糊 | agent | 开放 | 组织中的个体既是独立主体又是组织构成部分，系统未处理主客体同构 |
| AI 作为主体 | agent | 开放 | AI 系统表现出自主行动时是否应被当作主体 |
| 价值相对性 | value | 开放 | 价值是否因主体不同而完全相对？是否存在跨主体的普世价值？ |
| 张力度量 | tension | 开放 | 如何区分强张力和弱张力？当前三档置信度可能不够 |
| 语境边界划定 | context | 开放 | 语境之间的过渡是离散跳跃还是连续渐变？ |
| 需求与目标冲突 | need↔goal | 开放 | 满足需求有时阻碍目标，追求目标有时忽视需求（contradicts 边 hypothetical） |
| 约束与目标对抗 | constraint↔goal | 开放 | 约束天然限制目标扩展，但同时也是创造性的来源 |
| 决策瘫痪 | decision | 开放 | 张力过大或信息过于不完备时主体无法做出决策 |
| 风险不可见性 | risk | 开放 | 最大风险往往在认知盲区内，如何系统性扫描？ |
| 隐含目标 vs 声明目标 | latent-goal↔goal | 开放 | 行为偏离声明时隐含目标比声明目标更有预测力 |
| 目标漂移 vs 目标适应 | goal-drift | 开放 | 如何区分负面的方向丢失和正面的方向调整？ |
| 伪需求 vs 真实需求 | pseudo-need↔need | 开放 | 解决方案伪装成需求，如何从伪需求追溯到真实需求 |
| 硬约束的伪装 | hard-soft-constraint | 开放 | 软约束常被声明为硬约束以简化决策，如何识别？ |
| 约束传导正反馈 | constraint-cascade | 开放 | 约束传导可能形成正反馈恶化环路，如何检测和打破？ |
| 风险不对称 vs 行动 | risk-asymmetry↔goal | 开放 | 过度避险导致避险瘫痪，不行动的损失也需要计入 |
