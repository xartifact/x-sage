## Canonical rules blobs (added with the event-160 expected-byte vectors)

These are the D10 generator's canonical rules bytes, copied verbatim. They exist so the four
`rules_digest`/`rules_ref` constants can be **recomputed from the bytes** rather than compared with
each other: a mis-transcribed constant passes a constant-vs-constant check, which is exactly how one
shipped.
