# 推理语义边界

> 上游：[data-model.md](data-model.md)；执行：[inference.md](inference.md)。
> 本文替代旧草案对 Armstrong 公理与图关系的类比论证。

## 1. 对象与逻辑范围

Assertion 是带身份、来源和置信度的二元关系断言；Fact 是固定规则下的可导出事实。
规则只表达系统选择的推理，不把路径存在当作任意领域命题成立。
contradicts 表达张力，不等于逻辑否定或 owl:disjointWith。
enables 是导航，不是 depends-on 的逆，也不自动传递。

Armstrong 公理处理关系模式上属性集合之间的函数依赖，增广律并不等同于图的
跨谓词复合。instantiates 的至多一目标约束也不意味着节点上的实例化关系获得了
Armstrong 的全部图推导规则。本系统直接定义规则，不再借该类比证明可靠性。

## 2. 注解载体

存在性与最低置信度必须分离：

    K = { bottom < contested < hypothetical < confirmed }
    a + b = max(a, b)
    a * b = min(a, b)

bottom 表示没有证明，是 max 的单位元和 min 的吸收元；confirmed 是 min 的单位元。
contested 是存在且有争议的断言，不能用数值 0 同时表示不存在。
实现可以用 Option<Confidence>，不能把 None 与 Some(Contested) 合并。

有限全序上的 max/min 满足交换、结合、分配与幂等；有限节点、固定谓词、无新项
生成的条件下，求值单调且必然终止。终止不代表结果规模或计算时间可接受。

同一事实有 confirmed 与 contested 支撑时，effectiveConfidence 取 confirmed，
但同时返回争议支撑/证据标记；max 不能抹掉“有人反对”的审计事实。
本注解不是概率，不能解释为统计置信区间。

注解回答“有多强”，来源标记回答“怎么来的”，两者独立：

| 标记 | 成立条件 |
|---|---|
| `asserted` | **本方向**存在直接作者断言。R2 反向读法不算：作者没有如此声明 |
| `derived` | 存在非循环规则证明：>=2 跳的 R1、从直接定义断言得到的 R3、或对反向作者断言应用一次的 R2 |
| `disputed` | **所有**有效支撑或路径中存在 contested，不是只看最强证明 |

`R2(R2(A))` 回到作者方向，不构成第二个来源，单独它不得置 `derived`。
`max` 只作用于注解，不作用于这三个标记：一条 confirmed 事实仍可以是 disputed。

## 3. 封闭规则

| 规则 | 语义 | 生效条件 |
|---|---|---|
| R1 | p(s,m), p(m,o) 推出 p(s,o)，路径取 min，多路径取 max | transitive |
| R2 | p(s,o) 推出 p(o,s) | symmetric |
| R3 | 定义关系 p(s,o) 推出 depends-on(s,o) | formal-v1 |

R3 只需从活动定义断言生成单跳依赖种子，再对 depends-on 求闭包。
不需要先物化 is-a/part-of 的全量闭包才能获得同样的依赖可达性。

layer 校验、出度约束、环检查是提交约束，不是产生事实的规则。
不定义 is-a ∘ part-of、is-a ∘ contradicts 等混合关系的隐含组合。
若未来增加组合，必须单独规定含义、终止性、证明形式和预算，不从关系名字猜测。

## 4. 最小表示不替代权威

有限 DAG 的普通无权传递归约唯一，但这一结论不能直接覆盖多来源、带注解、
对称边和跨谓词蕴含的整个记录系统。不得用它证明“权威断言可以自动删到最少”。

反例：独立录入 A→C、A→B、B→C。第一条当前可由后两条推导，
但撤回 B→C 后，A→C 应继续成立。若导入时删除第一条，撤回语义已改变。

因此：

- 权威保留每条 Assertion 的身份、修订、理由和来源。
- 计算索引可以聚合重复三元组；冗余检测只给审阅建议，不自动撤回。
- 若以后采用计算图归约，必须保留支撑映射并验证任意后续撤回后的结果；v1 不做。
- 闭包相同是迁移必要条件之一，不足以证明历史、证据和后续行为相同。

## 5. 未知与不成立

完整查询返回 absent，只表示在指定版本、规则配置和记录范围内不可推导，
不表示现实世界命题为假。预算未完成返回 unknown/incomplete，不能返回 absent。
contradicts(a,b) 也不等于 not p(a,b)，本系统没有开放的否定规则。

显式路径 * 的零跳匹配是查询 Identity，不写入 Fact，不参与 self-reference 校验。
+ 至少一跳，仅允许 transitive 关系。对非传递关系，仍可进行有深度限制的导航，
但导航路径不得被输出成新的语义事实。

## 6. 必须成立的测试性质

1. 输入顺序不改变事实注解；证明在规定的平局规则下确定。
2. 同一规则重复求值达到不动点；加入弱路径不降低已有置信度。
3. 删除最强支撑后保留较弱替代；删除最后支撑后变 absent。
4. contested 支撑单独存在时仍可查询与解释。
5. asserted 与 derived 同时成立时保留两种来源；撤回其一不误删另一种。
   反向读法只产生 derived，不产生 asserted；`R2(R2(A))` 不新增来源；
   disputed 覆盖全部有效支撑而非仅最强证明。
6. formal-v1 的 R3 能回溯到具体定义 Assertion，而非生成无来源依赖。
7. 同一版本的所有查询在有无缓存时有相同语义结果。
8. 证明中每个叶子都对应该版本内活动的 Assertion 修订。
