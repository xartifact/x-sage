# L1 核心概念候选：由 L0 定义的主干词汇

## 前提

以下概念均依赖 L0 层的四个公理（主体、价值、语境、张力）才能被定义。
它们是产品/项目和个人思想体系的主要操作词汇。

---

## 目标 Goal

**定义**：主体在特定语境下基于价值想要达到的状态。

**依赖 L0**：主体 + 价值 + 语境

**跨域**：
- 产品：产品目标、用户目标、业务目标
- 项目：里程碑、交付物、成功标准
- 个人：人生目标、阶段性目标

---

## 约束 Constraint

**定义**：在特定语境下限制主体可能行动空间的条件。

**依赖 L0**：主体 + 语境

**跨域**：
- 产品：技术约束、资源约束、合规要求
- 项目：时间、预算、人力
- 个人：能力边界、外部条件、承诺

---

## 决策 Decision

**定义**：主体在张力中，于约束条件下做出的选择。

**依赖 L0**：主体 + 张力；依赖 L1：约束

**跨域**：
- 产品：产品方向、功能取舍、技术选型
- 项目：优先级排序、资源分配
- 个人：人生选择、行动取舍

---

## 需求 Need

**定义**：主体在特定语境下，价值缺口导致的必须被满足的状态。

**依赖 L0**：主体 + 价值 + 语境

**跨域**：
- 产品：用户需求、功能需求、非功能需求
- 项目：资源需求、信息需求
- 个人：心理需求、物质需求

---

## 风险 Risk

**定义**：在特定语境下，目标实现可能被破坏的不确定张力。

**依赖 L0**：张力 + 语境；依赖 L1：目标

**跨域**：
- 产品：市场风险、技术风险、用户流失
- 项目：交付风险、依赖风险
- 个人：判断失误、外部变化

---

## 关系图

```
L0: 主体 ── 价值 ── 语境 ── 张力
              │        │        │
L1:         需求     目标     风险
              │        │
            约束     决策
```

## 待补充

个人思想体系域成熟后，以下 L1 概念可能需要加入：

| 候选 | 依赖 L0 | 说明 |
|------|---------|------|
| 信念 Belief | 主体 + 语境 | 主体认为为真的命题（若 Belief 升为 L0 则此项取消） |
| 视角 Perspective | 主体 + 语境 | 主体观察世界的特定角度 |
| 意图 Intention | 主体 + 目标 | 主体对目标的承诺状态 |
